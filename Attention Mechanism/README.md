# Experiment 4 — Attention Mechanism

## Objective
To understand how attention enables models to dynamically focus on relevant parts of input.

---

## Core Idea

Attention computes relationships between tokens and assigns importance scores.

---

## System Flow

Input → Q/K/V Projection → Attention Scores → Softmax → Weighted Output

---

## Experiments Conducted

1. Attention weight visualization  
2. Token interaction analysis  
3. Multi-head attention comparison  
4. Input perturbation sensitivity  
5. Attention entropy analysis  

---

## Results

- Attention captures token relationships dynamically  
- Multi-head attention improves representation diversity  
- Small input changes affect global behavior  

---

## Failure Modes

- No positional awareness  
- Random weights lack semantic meaning  
- Sensitive to scaling  

---

## Conclusion

Attention is the core mechanism behind transformers and modern LLMs.
