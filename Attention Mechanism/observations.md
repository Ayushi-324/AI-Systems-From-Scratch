# Observations — Attention Mechanism

## Attention Weights
- Each token distributes focus across all tokens
- Some tokens dominate attention patterns

## Token Relationships
- Attention reveals implicit relationships between tokens
- Model dynamically decides importance

## Multi-Head Attention
- Different heads capture different interaction patterns
- Improves representational richness

## Sensitivity to Input
- Small input changes shift global attention distribution
- Indicates high coupling across tokens

## Entropy Analysis
- Low entropy → focused attention
- High entropy → distributed attention

## Key Insight
Attention is not just weighting — it is dynamic information routing.
