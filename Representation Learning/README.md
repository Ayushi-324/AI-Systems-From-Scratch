# Experiment 2 — Representation Learning

## Objective
To visualize how neural networks transform data into separable representations.

---

## Core Idea

Neural networks learn by transforming input space into a new feature space where classes become separable.

---

## System Flow

Input → Hidden Layers → Feature Transformation → Output

---

## Experiments Conducted

1. Raw input visualization  
2. Hidden layer representation (Layer 1)  
3. Hidden layer representation (Layer 2)  
4. Combined transformation comparison  
5. Decision boundary visualization  
6. Distance transformation analysis  

---

## Results

- Hidden layers progressively structure the data  
- Final representation enables linear separability  
- Model reshapes geometry, not just decision rules  

---

## Failure Modes

- Shallow networks fail to separate complex data  
- Poor initialization limits transformation  
- Lack of depth reduces representational power  

---

## Conclusion

Representation learning is the foundation of deep learning — models succeed by transforming data, not memorizing it.
